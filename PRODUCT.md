# Quadrion client portal

## Register

product

## Users

Invited engineering and geospatial clients download Quadrion installers, processing pipelines and authorized AIO projects. The owner and administrators manage access and publish library content from desktop workstations, with mobile access for account and user administration.

## Product Purpose

Provide an invite-only software and project library. T1 receives software and pipelines; T2 adds basic projects; T3 adds all categories. Private assignments intersect the tier. Separate administrator roles manage users and publication, with MFA required for administration.

## Brand Personality

Precise, calm and approachable. Continue the existing Quadrion website identity, using its IBM Plex typography and teal accents. Use direct language that explains the result of each access change.

## Anti-references

The portal is a working application: no heavy marketing 3D tour, decorative animation, repeated metric cards or fake project previews. Do not revive the removed bottom demo/free-player buttons. Do not add Arabic content.

## Design Principles

- Show the user's actual access and current published versions.
- Keep tiers separate from administrator roles.
- Make draft, validation and publication distinct, visible steps.
- Use plain labels, searchable lists and inline forms.
- Clear private data immediately when access is lost.

## Accessibility & Inclusion

Keyboard navigation, visible focus, labelled controls, reduced motion, legible contrast and responsive layouts at 360 px are required by the accepted portal specification. Pair colour states with text.
